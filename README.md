# AI Development Basics

A practical, searchable knowledge repo for day-to-day AI-assisted development.

## What this repo is for

- Capture useful notes quickly while working.
- Reuse known fixes and patterns across projects.
- Build a personal library of cheatsheets and agent blueprints.
- Track your journey with lightweight logs.

## Fast start (2 minutes)

1. Add raw notes to `inbox/`.
2. Promote valuable notes to `issues/`, `cheatsheets/`, or `blueprints/`.
3. Add tags to each note for fast lookup.

## Folder map

- `inbox/`: quick capture, rough notes
- `issues/`: problem/solution records
- `cheatsheets/`: short operational guides
- `blueprints/`: reusable agent workflow markdown files
- `journey/`: timeline and progress snapshots
- `references/`: links and short why-it-matters summaries
- `templates/`: copy-ready templates
