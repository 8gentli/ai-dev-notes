## Goal

- Get oriented in VS Code fast and use the core views without hunting around.

## Fast steps

1. Open a folder first: use File > Open Folder or `Ctrl+K Ctrl+O`.
2. Learn the main views: Explorer, Search, Source Control, Run and Debug, Extensions, and Terminal.
3. Use the Command Palette with `Ctrl+Shift+P` when you do not remember a command.
4. Open Chat with `Ctrl+Alt+I` when you want AI help inside the editor.
5. Save early with `Ctrl+S`, and turn on Auto Save if you prefer fewer manual saves.

## Gotchas

- Shortcuts can vary by platform and keyboard layout.
- The Command Palette is often faster than clicking through menus.
- If the UI feels crowded, use the sidebar and panel toggles instead of opening new windows.
