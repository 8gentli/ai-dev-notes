## Goal

- Keep the most useful VS Code shortcuts in one compact reference.

## Fast steps

1. Open a folder: `Ctrl+K Ctrl+O`.
2. Open the Command Palette: `Ctrl+Shift+P`.
3. Open Chat: `Ctrl+Alt+I`.
4. Switch to Explorer / Search / Source Control / Run and Debug / Extensions with `Ctrl+Shift+E`, `Ctrl+Shift+F`, `Ctrl+Shift+G`, `Ctrl+Shift+D`, `Ctrl+Shift+X`.
5. Open Output / Debug Console / Problems / Terminal with `Ctrl+Shift+U`, `Ctrl+Shift+Y`, `Ctrl+Shift+M`, and `Ctrl+``.
6. Create a new file with `Ctrl+N`, save with `Ctrl+S`, and use Auto Save if you want fewer manual saves.
7. Start debugging with `F5`.
8. Zoom out or in with `Ctrl+-` and `Ctrl+=`.

## Gotchas

- Shortcuts can differ by keyboard layout.
- The exact shortcut labels can vary by platform, but the command names stay the same.
- Use the Command Palette when you do not remember the shortcut.
