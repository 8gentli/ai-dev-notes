# Agents Rulesets

These files could help to quickly setup the most important general rules for agentic development with only little context usage.

As the following platforms natively work with AGENTS.md, tool specific instruction files (in brackets) are optional:
- Hermes (.hermes.md)
- OpenClaw (OPENCLAW.md)
- Antigravity (GEMINI.md)
- Cursor (.cursorrules)
- VSCode, Github Copilot (.github/copilot-instructions.md)

Only Claude Code first reads CLAUDE.md, that imports AGENTS.md as single source.
